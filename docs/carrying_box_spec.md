# curcur40 キャリングボックス設計仕様書 (`carrying_box_spec.md`)

本書は、左右分割キーボード `curcur40`（ビルトインテンティング角 `11.80°`）を、**USB-C マグネット端子 4個・底面埋め込み折りたたみスタンド 4本・25 mm トラックボール球・底面ゴム足（高さ `≤ 3.0 mm`）をすべて装着したまま 6面フルカバーの直方体ブロックとして収納・携行できるオプションケース**（[`cases/carrying-box.step`](../cases/carrying-box.step) ＋ [`cases/carrying-box-lid.step`](../cases/carrying-box-lid.step)）の設計仕様と力学根拠を定義します。

- 対応スクリプト: [`scripts/generate_carrying_box.py`](../scripts/generate_carrying_box.py)
- 体験型インタラクティブ図解: **[`docs/carrying_box_lid_guide.html`](./carrying_box_lid_guide.html)**（スナップフタの浅角カム開閉動作をブラウザ上で操作可能）

## 1. 互い違いウェッジ相殺配置と外形仕様

### 1.1 テンティング傾斜の完全相殺（`Rot_X(180°)`）
- 右手キーボード（`right.step`、リム天面 `Z = 0.00 mm`）を基準とし、左手キーボード（`left.step`）をキー面同士が内側で向かい合うよう X軸まわりに `180°` 反転して対面配置します（離隔高さ `H_sep = 16.50 mm`）：
  - `X' = x_L + 152.9080`, `Y' = -y_L - 149.3750`, `Z' = -z_L + 16.5000`
- 右ケースの親指側（高さ `39.02 mm`）に左ケースの小指側（高さ `14.20 mm`）が、右ケースの小指側に左ケースの親指側が重なることで、左右の `11.80°` テンティング角が数学的に完全相殺され、外殻天面・底面が水平（`0.000°`）、前後左右側面が垂直（`90.000°`）の真の直方体となります。

### 1.2 上下完全リバーシブル構造と外形寸法
ボックス本体・スナップフタともに **Y軸（差し込み軸）まわり `180°` 完全回転対称** に設計されているため、**右手トラックボール側を下にしても上にしても（箱・フタの上下向きを一切気にせず）そのまま差し込んで閉められます**。

| 項目 | 外形寸法 (`X × Y × Z`) | 体積 / 備考 |
| :--- | :---: | :--- |
| **ボックス本体 (`carrying-box.step`)** | **`140.20 × 103.79 × 80.25 mm`** | 体積 `272.18 cm³`、奥面貫通穴ゼロ、上下点対称 |
| **スナップフタ (`carrying-box-lid.step`)** | **`140.20 × 80.25 × 24.15 mm`** | 体積 `73.12 cm³`、外正面フルフラット穴なし、上下点対称 |
| **フタ装着時 総外寸** | **`140.20 × 110.44 × 80.25 mm`** | 幅・高さ方向へのフタ出っ張り `0.00 mm` |

## 2. 内部保持・クリアランス保護構造

1. **ゴム足フローティング Cレール（深さ `4.00 mm`）**:
   - 天板・底板の内側を `4.00 mm` 掘り下げた `11.80°` 点対称ガイドレールにより、高さ `3.00 mm` の厚手ゴム足を貼った状態でも常時 **`1.00 mm` 以上**（折りたたみスタンド上貼付時は `1.18 mm`）空中に浮いた状態で出し入れでき、ゴム足の擦れや剥がれが発生しません。
2. **点対称クランク段差ディバイダ ＆ デュアル U字トラックボールキーパー**:
   - 中央隔壁（肉厚 `2.25 mm`、軽量化窓 `10 × 34 mm × 2` 付）を西側 `Z_asm ∈ [+9.80, +12.05] mm`・東側 `Z_asm ∈ [+4.45, +6.70] mm` の点対称クランク形状とし、両側に幅 `15.60 mm` の U字キーパースロットを設けています。
   - 箱高さを増やすことなく、右手トラックボール（頂点 `Z = +11.80 mm`）が下段・上段どちらに入っても `0.58 mm` の非接触クリアランスと `≤ 0.73 mm` のボール脱落阻止を両立します（全キーキャップまで `≥ 0.85 mm`、慣性ホイールまで `6.23 mm`）。
3. **貫通穴ゼロの前後デュアル内部「堀」と側面保護スロット**:
   - **奥面（左北 `J1` マグネット端子逃げ）**: 南奥外壁（肉厚 `2.20 mm`）は貫通穴ゼロの密閉壁とし、手前のストッパー段差でケースを受け止めつつ、対角 2箇所の内部堀（`17.60 × 11.60 × 深さ 4.55 mm`）へ `CIO-SLMG-T-C` 等のマグネット端子を非接触収容（最小隙間 `1.00 mm`）します。
   - **フタ内面（右北 `rJ1` マグネット端子逃げ）**: フタ外正面も貫通穴ゼロとし、内面対角 2箇所の内部堀（`18.60 × 12.80 × 深さ 4.30 mm`）で `2.29 mm` 以上のクリアランスを確保します。
   - **東西側面スロット**: 西壁下部・東壁上部に高さ `9.50 mm` の水平スライドスロットを備え、側面 USB-C マグネット端子が垂直外壁より `3.73 mm` 内側に保護されたままスライドできます。

## 3. 長スパン・浅角カム式スナップフタ力学設計

ネジや磁石を使わず、フタ左右の指掛け溝（深さ `1.20 mm`）を持って **手前（`+Y` 方向）へ真っ直ぐ引くだけでセルフロックせずに抜ける隠しスナップ機構** です（視覚的な動作解説は [`docs/carrying_box_lid_guide.html`](./carrying_box_lid_guide.html) を参照）。

- **弾性梁・カム諸元**:
  - 自由梁長 `L = 14.0 mm`、梁厚 `t = 1.85 mm`、梁幅 `b = 9.5 mm`、内側たわみ逃げ隙間 `0.85 mm`、掛かり量 `δ = 0.50 mm`
  - 浅角カム斜面: **抜き角 `α_out = 26.0°`** ／ **押し込み角 `α_in = 20.0°`**
- **力学検証値（PA12 ナイロン基準）**:
  - カム開放モーメントが偏心食い込みモーメントの **`8.61 倍`**（限界セルフロック摩擦係数 `μ_crit = 1.53 ≫ 0.30`）を確保しており、片引きでもこじれず内側へスムーズにたわみます。
  - **引き抜き力**: **`9.73 N`（約 `0.99 kgf`）** ／ **押し込み力**: **`6.35 N`（約 `0.65 kgf`）**
  - **根元最大曲げひずみ**: **`0.71 %`**（PA12 弾性限界に対する安全率 `4.94 倍`）
- **指掛け切り欠きと仮保持ストッパー**: ボックス上下の中央指掛け切り欠き（幅 `32.0 × 深さ 15.0 mm`）をフタ側の角丸タングがツライチに塞ぎ、フタを外した状態でも入口のクリックストッパーがキーボードの不意な滑り出しを防ぎます。
