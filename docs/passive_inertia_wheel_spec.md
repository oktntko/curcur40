# アンダープレート一体軸パッシブ磁気慣性ホイール 設計仕様書

本書は、電磁クラッチ（ソレノイド・コイル・駆動回路）や専用サブ基板・手配線ハーネス・接着剤・シムリング・スナップカバーを一切使わずに、**「1ピース一体軸 `45# Steel` CNC フライホイール（$\varnothing 22.00 \times 4.65\,\text{mm}$, $13.51\,\text{g}$、黒染め仕上げ＋同名2D公差図面 [`steel-flywheel.pdf`](../cases/inertia_wheel/steel-flywheel.pdf) 付属） × 脱脂 `DDL-520ZZ` ミニチュアベアリング × 接着剤ゼロ・抜け止め付きの24極磁気デテント × 右メイン基板 PCBA 直実装 3Dホールセンサー（`TMAG5273`）」** によって、**『普段は心地よい24ノッチ感があり、指で弾けば慣性モーメント（$J \approx 774\,\text{g}\cdot\text{mm}^2$）で数秒間回り続け、指で触れれば瞬時にピタッと止まる』** 高速慣性スクロール＆静音ミドルクリックを実現し、かつ **JLC3DP / JLCCNC 公式デザインガイドライン・発注ガイドラインの全項目（最小造形サイズ $\ge 5\times 5\times 5\,\text{mm}$、穴深さ比 $h/\Phi \le 3.0$、肉厚 $\ge 1.20\,\text{mm}$／突起・爪 $\ge 1.50\,\text{mm}$、CNC 工具最小 $R=1.50\,\text{mm}$、公差 $\pm 0.02\,\text{mm}$）に100%準拠**したハードウェア・ファームウェア設計仕様書です。

### 0.1 高速スクロールのしくみと `#02 マグネットホルダー` の場所（「重い鉄のコマ × 空中コンパス」）
* **なぜ一度はじくと「シューーーッ！」と長く回り続けるの？**
  軽いプラスチックではなく、**幅 $4.65\,\text{mm}$・重さ $13.51\,\text{g}$（10円玉3枚分のズッシリ感！）** の「`#01` 鉄のコマ」を、2個のミニチュアベアリング（`#07`）で支えているからです。自転車の車輪と同じで、指ではじけば重さの勢い（慣性）で何秒も回り続け、止めたいときは指先で軽く触れるだけでその瞬間にピタッと止まります。
* **`#02 マグネットホルダー` はどこで何をしているの？**
  `#01` 鉄のコマから右（東・キーマトリクス側）へ伸びた「かまぼこ型（Dカット）の鉄の軸」の先端にスポッと刺さっている**小さな丸いキャップ（$\varnothing 6.64 \times 5.05\,\text{mm}$）が `#02 マグネットホルダー`** です。中に **`#08` 赤青2極磁石（N極・S極）** を入れて軸と一緒にくるくる回します。左側は東ベアリング内輪と鉄の軸の段差、右側は `#03` ロッカーから立ち上がる **「抜け止め壁（キーパータブ）」** に挟まれているため、**接着剤ゼロでも絶対に抜け落ちません**。
* **どうやって回転を読み取っているの？（こすれゼロ！）**
  右メイン基板の裏面に最初から付いている **`#05` 空中コンパス（3D磁気センサー `rU6: TMAG5273`）** が、`#08` 磁石に一切触れずに空中から「いま磁石が何時の方角を向いているか」を毎秒約1,000回キャッチします。こすれる部品がゼロなのでブレーキがかかりません。

### 0.2 ノッチ（カリカリ感）調整のしくみ（「24個の鉄の山 × 磁石つきネジの距離あそび」）
* **`#01` 鉄のコマの外周には 24個の「山」と「谷」** が彫られています。そのすぐ南側（親指側）のトンネル（`#03` 南ボス＋`#10` 真鍮インサート）に **`#11` 鉄のネジ** をねじ込み、ネジの先端に **`#09` 小さな磁石** を磁力でパチンとくっつけます（ボンド不要！）。
* 磁石は遠い「谷」より近い「山」を強く引っ張るため、コマが回るたびに山から山へ **1周24回の「カチ・カチ・カチ！」という気持ちいいノッチ感** が生まれます。
* **ドライバー1本で好みの重さにチューニング可能！（基板へのネジ止め前に調整）**:
  * **ネジを右へ回して磁石を近づける** → 磁力が強まり「カチカチ！」としっかり止まる24ノッチモード（最奥まで締めても北端の抜け止め顎が磁石を確実にストップするため、ホイールに磁石が張り付く心配はゼロ！）
  * **ネジを左へ回して磁石を遠ざける** → 磁力がフワッと弱まり、引っかかりゼロの「ツルツル無限スピン」モード
  * 空中の磁力で引っ張っているだけなので、プラスチックのツメやバネと違って **何万回まわしても一生すり減りません**（※調整ネジは右メイン基板の下に収まるため、右メイン基板へ `WC1`/`WC2` ネジで固定する前の単体状態で好みの感触へ合わせておきます）。

### 0.3 背面スイッチへのミドルクリックのしくみ（「パチンと連結したCクリップ支点のシーソーで基板ウラの赤いボタンを下からポチッ！」）
* ホイールを支えている `#03 シーソーロッカー` は、文字どおり **「公園のシーソー」** になっています。
* 真ん中の丸い支点棒（直径 $\varnothing 3.20\,\text{mm}$）は、`#04 クレードル` の **「スリット分離型Cクリップ軸受け（内径 $\varnothing 3.50\,\text{mm}$・上開口 $2.80\,\text{mm}$・肉厚 $1.55\,\text{mm}$）」** に上から **「パチン！」と弾性スナップイン連結** されます。だから基板にネジ止めする前の単体状態でも上にも横にも抜け落ちず、回転（シーソー運動）だけができる安心の機械ヒンジになっています。
* 指でシーソーの左側（`#01` ホイール）を下にグッと押すと（わずか $0.33\,\text{mm}$ 沈むだけ）、支点の反対側にある北東うでが **「上」に向かって持ち上がり**、基板の裏に逆さまに付いた **`#06` 静音スイッチ (`rEXSW1`) の赤いボタンを下からポチッ！** と押します。
* 支点からホイール側（$6.35\,\text{mm}$）とスイッチ側（$4.66\,\text{mm}$）のてこ比により、約 **$50\sim 55\,\text{gf}$** の歯切れよい力で静かにミドルクリックでき、強く押しすぎても西側のハードストッパーが受け止めてスイッチを保護します。

## 1. 第一原理からの設計思想（複雑さの徹底排除 ＆ 公式製造ガイドライン100%適合）

従来の自作キーボード用ホイール機構で発生しがちだった「部品点数の肥大化・接着剥がれ・シム調整・極細線の断線・カバー干渉・ガタつき・3DP/CNC 発注時の自動審査リジェクト」を第一原理から見直し、以下のゼロベース統合アーキテクチャを採用しています。

| 設計課題 | 旧来のアプローチで起きやすい無理 | 本設計（アンダープレート一体軸方式）の解決策 |
| :--- | :--- | :--- |
| **① 軸・シム・同軸度** | 別体平行ピン＋オープン軸受＋極薄シムリング重ね | **`steel-flywheel.step` に $\varnothing 3.00\,\text{mm}$ 内輪当たり段付き肩（$R=0.50\,\text{mm}$ 旋削逃げ溝付）・$\varnothing 1.97\,\text{mm}$ ジャーナル・東Dカット軸を1ピース一体切削**。標準両シールド **`DDL-520ZZ`（幅 $2.30\,\text{mm}$）** を挿し、`#03` の **Cクリップスナップ軸受座** へパチンと嵌めるだけでシムリング不要・上抜けゼロ。 |
| **② 大慣性と低背化・公式最小造形サイズの両立** | 軸を上に出すと背が高くなり、極小ホルダーは JLC3DP 最小サイズ未満で注文不可になる | テンティングケース内の深い空間を活かし、回転軸をプレート下 **$Z = -7.38\,\text{mm}$** に配置。**外径 $\varnothing 22.00\,\text{mm}$ × 幅 $4.65\,\text{mm}$・質量 $13.51\,\text{g}$（$J = 774\,\text{g}\cdot\text{mm}^2$）** の大慣性と、JLC3DP 公式最小サイズ（$\ge 5\times 5\times 5\,\text{mm}$）＆肉厚 $\ge 1.20\,\text{mm}$ を満たす **`#02` マグネットホルダー（$\varnothing 6.64 \times 5.05\,\text{mm}$）** を基板変更ゼロで収容しつつ、頂点 **$Z = +3.62\,\text{mm}$（Choc V2 キーキャップ天面 $+3.60\,\text{mm}$ とほぼ完全ツライチ）** の超低背を実現。 |
| **③ センサー基板と手配線** | 同軸対向のために極小サブ基板を垂直立て＋6芯手配線 | 右メイン基板 `B.Cu` のホイール窓東横に **3軸リニアホールIC `rU6`（`TMAG5273A1QDBVR`, PCBA自動実装）** を配置し、軸端正面横（off-axis）から回転磁界 $(B_x, B_z)$ を直接ベクトル復調。**サブ基板・JST SH コネクタ・手配線ケーブルを完全ゼロ化**。 |
| **④ 磁気ラチェット構造と表面処理・CNC公差** | 非磁性ホイール＋別体ハブ、めっき厚による軸太りや小径工具不可な細溝 | ホイール自体を **強磁性炭素鋼 `45# Steel`（S45C）＋ 公式 `Blackening`（黒染め：膜厚 $\le 2\,\mu\text{m}$ で軸太りゼロ）** で製作し、JLCCNC 工具基準（`Minimum R = 1.5 mm`）に準拠した **外周 24本 × $R=1.50\,\text{mm}$ フルート溝** を指掛け兼・磁気ラチェット歯として共用。さらに同名2D公差図面 **[`steel-flywheel.pdf`](../cases/inertia_wheel/steel-flywheel.pdf)** で軸部 **`⌀1.97 ±0.02 mm`**（JLCCNC 公式最小公差範囲内）を明示。 |
| **⑤ 磁石固定と接着剤排除** | 回転軸端やイモネジ先端への瞬間接着剤点付け | 角度磁石（`#08` `D4×1mm` 径方向着磁）は **`#02` マグネットホルダー** に入れ `#01` 軸・軸受と **`#03` 東一体キーパー壁** で両方向ロック。ラチェット磁石（`#09` `NE280`）は **鉄製 `M2×6.0mm` ネジ先端に自己磁力で吸着**。**接着剤完全ゼロ**。 |
| **⑥ 外装カバーとプレート固定** | 軸受・基板を隠す別体スナップカバーや外周の目立つネジ穴 | 機構全体がトッププレート下面（$Z = -3.60\,\text{mm}$）より下に収まるため、**トッププレート開口はホイールと同心の $6.55 \times 22.00\,\text{mm}$ 角丸長穴（静止時左右 $0.95\,\text{mm}$ 等幅・東ベアリング遮蔽）1つだけ**。キー谷間12箇所のコンパクト $\varnothing 5.20\,\text{mm}$ フラットボス（外周むき出し穴ゼロ）でメイン基板を直接ネジ固定し、ネジ頭はプレート頭逃げ穴（`WC1` $\varnothing 4.05\,\text{mm}$ / 他 $\varnothing 4.40\,\text{mm}$）下に沈み込み、プレートは 39個の Choc V2 スイッチ嵌合で保持。 |

### 2.1 座標系定義（回転軸ローカル座標 $(u, v, w)$ ⇔ グローバル座標）
右手メイン基板上の南側隣接キー `rEXSW2` $(14.2875, 23.8125)$ の X 中心線と交わる回転軸基準点 **$(x_{\text{pcb}}, y_{\text{pcb}}) = (14.2875, +2.7625)\,\text{mm}$**（フルアセンブリ STEP 座標 **$(X_{\text{step}}, Y_{\text{step}}, Z_{\text{step}}) = (+28.5750, -59.9125, -7.3800)\,\text{mm}$**）をローカル座標原点 $(u, v, w) = (0, 0, 0)$ とする平行移動座標系で定義します（※東側の `#02` $5.05\,\text{mm}$ マグネットホルダー＋東ベアリング＋`rU6` を `rSW3` スイッチ穴手前に収めつつ最大リム幅 $4.65\,\text{mm}$ を確保するため、ホイールリム実体 $u \in [-3.25, +1.40]\,\text{mm}$ およびトッププレート長穴 $u \in [-4.20, +2.35]\,\text{mm}$ の左右中心は $u = -0.9250\,\text{mm}$［$x_{\text{pcb}} = 13.3625\,\text{mm}$］となります）：
* **$u = x_{\text{pcb}} - 14.2875$**（$+u$: 東＝キーマトリクス・支点・`rU6`/`rEXSW1` 側、$-u$: 西＝キーボード内側・西壁張り出しゼロ）
* **$v = -(y_{\text{pcb}} - 2.7625)$**（$+v$: 北＝PC側USBポート方向、$-v$: 南＝親指トラックボール方向）
* **$w = Z_{\text{step}} - (-7.3800)$**（メイン基板 `B.Cu`: $w = +1.58$ / `F.Cu`: $w = +3.18$、トッププレート: $w \in [+3.78, +5.38]$）

### 2.2 4つの製造パーツ詳細仕様（[`cases/inertia_wheel/`](../cases/inertia_wheel/)）

1. **`#01` 1ピース一体軸スチールホイール（[`steel-flywheel.step`](../cases/inertia_wheel/steel-flywheel.step) ＋ 同名2D公差図面 [`steel-flywheel.pdf`](../cases/inertia_wheel/steel-flywheel.pdf) — JLCCNC `45# Steel` + `Blackening`［黒染め］）**:
   * **外周リム**: 外径 **$\varnothing 22.00\,\text{mm}$**（クレスト実寸 $21.90\,\text{mm}$）× **幅 $4.65\,\text{mm}$**（$u \in [-3.25, +1.40]\,\text{mm}$）。外周に **JLCCNC デザインガイドライン表 Row 1（`Tool ⌀2.0mm, Minimum R = 1.5mm`）完全準拠の $R = 1.50\,\text{mm}$・深さ $0.45\,\text{mm}$ フルート溝（谷径 $\varnothing 21.10\,\text{mm}$）を $15^\circ$ ピッチで 24本** 加工し、指先のグリップと強磁性24ノッチ磁気デテント極を兼用します。
   * **一体内輪フラットショルダー ＆ DIN 509 旋削逃げ溝**: $u \in [-3.70, +1.70]\,\text{mm}$（スパン厳密 **$5.400\,\text{mm}$**、`steel-flywheel.pdf` 完全一致）に外径 **$\varnothing 3.00\,\text{mm}$** の垂直平面段付き肩（$r \in [1.00, 1.50]\,\text{mm}$）を一体旋削し、肩付け根2箇所に **DIN 509 E形準拠 $R = 0.20\,\text{mm}$ 径方向旋削逃げ溝（首径 $\varnothing 1.60\,\text{mm}$、$r_{\tan} = 1.000\,\text{mm}$）** を設けることで、内角 $R=0$ を排除しつつ `DDL-520ZZ` 内輪端面を浮き・乗り上げゼロで垂直肩へ確実着座させます（シムリングゼロ）。
   * **一体ベアリングジャーナル ＆ 東側Dカット軸**: $u \in [-5.95, +6.50]\,\text{mm}$（全長 $12.45\,\text{mm}$）の公称 **$\varnothing 1.970\,\text{mm}$** 一体軸。JLCCNC 発注ガイドライン第3節（「公差要件がある場合は 3D ファイルと同じ名前の 2D 図面を添付」）に従い、同梱の **[`steel-flywheel.pdf`](../cases/inertia_wheel/steel-flywheel.pdf)** にて **黒染め後仕上がり軸径 `⌀1.97 ±0.02 mm`（`1.950〜1.990 mm`：JLCCNC 公式最小公差 `±0.02 mm` 以内、`DDL-520ZZ` 内径 `⌀2.000 -0.004/+0` に確実挿入）** を指定します。東端 $u \in [+5.15, +6.50]\,\text{mm}$（長さ $1.35\,\text{mm}$）の Dカット平面（中心から $+0.68\,\text{mm}$）切り上がりにも **$R = 1.50\,\text{mm}$ 工具スイープ逃げ** を付与しています。
   * **質量・回転慣性**: 体積 $1721.5\,\text{mm}^3$、質量 **$13.51\,\text{g}$**、軸回り慣性モーメント **$J = 773.6\,\text{g}\cdot\text{mm}^2$（約 $774\,\text{g}\cdot\text{mm}^2$）**。

2. **`#02` 接着剤ゼロ マグネットホルダー（[`magnet-holder.step`](../cases/inertia_wheel/magnet-holder.step) — JLC3DP MJF/SLS PA12）**:
   * 外径 **$\varnothing 6.64\,\text{mm}$** × 長さ **$5.05\,\text{mm}$**（$u \in [+4.00, +9.05]\,\text{mm}$、バウンディングボックス **`6.64 × 6.64 × 5.05 mm`**）。ランナー連結（JLC3DP 禁止の1ファイル複数モデル）に頼らず、単一モデルのまま **JLC3DP 公式最小造形サイズ（$5.0 \times 5.0 \times 5.0\,\text{mm}$）** および **全箇所肉厚 $\ge 1.20\,\text{mm}$（`<1.20mm` 違反 0件）** を完全に満たします（$2.95^\circ$ フルクリック時もプレート下面・基板切り欠きと $\ge 0.31\,\text{mm}$ 非接触）。

## 3. オンボード 3D ホール磁気センシング ＆ ファームウェア信号処理

### 3.1 Off-Axis 2成分磁気ベクトル検出原理
* 回転軸東端の `D4×1mm` 径方向2極着磁磁石が1回転すると、その東側にある右メイン基板 `B.Cu` 上の 3軸リニアホールセンサー **`rU6`（`TMAG5273A1QDBVR`）** 位置では、基板水平成分 $B_x$ と基板法線成分 $B_z$ が互いに $90^\circ$ 位相のずれた正弦波・余弦波として回転します。
* これにより、磁石の軸延長線上に別基板を垂直に立てる必要が一切なく、メイン基板裏面の SMD IC 1個だけで $0^\circ \sim 360^\circ$ の絶対回転角を非接触で連続復調できます。

### 3.2 高速フリック対応 QMK / Vial ドライバ（[`curcur40_scroll.c`](../kbd_firmware/keyboards/curcur40/qmk/qmk_firmware/rev1/curcur40_scroll.c)）
1. **デュアルセンサー自動プローブ（`TMAG5273` ＆ `TLV493D-A1B6` 両対応）**:
   * 起動時およびバスリカバリ時に `I2C0`（`GP24`/`GP25`, `400 kHz`）上で TI `TMAG5273`（A1:`0x35`, B1:`0x22`, C1:`0x78`, D1:`0x44`）を優先検出し、未検出時はピン互換の Infineon `TLV493D-A1B6`（`0x5E`, `0x1F`、右手系 X/Y 入替に伴う `(-By, -Bz)` 極性整合＆ `FRM` カウンタ凍結監視対応）へ自動フォールバックします。
2. **`XZX` 擬似同時サンプリングによる高速スピン位相スキュー除去（`TMAG5273`）**:
   * `TMAG5273` を低雑音連続変換モード（`CONV_AVG = 4x` $\approx 3.1\,\text{kSPS}$、感度レンジ `±80 mT`［`A2` 系は `±266 mT`］）かつ **`MAG_CH_EN = XZX` モード** で駆動します。チップ内部で `X1 → Z → X2` の順にAD変換し $(X_1 + X_2)/2$ と $Z$ の時刻重心を完全一致させるため、指で強く弾いた **毎分千回転クラスの高速フリースピン中でも角度位相遅れが発生しません**。
3. **4象限対称ロック付き適応型 Max/Min 包絡線正規化 ＋ 12-bit 整数 CORDIC `atan2`**:
   * Off-axis 配置の $|B_x| : |B_z|$ 振幅比（$Z_{\text{axle}} = -7.38\,\text{mm}$ 実配置で約 $1.40:1$：未1回転の起動直後から初期補正 `nc = (nc * 358) >> 8` を適用）および磁石個体差・温度ドリフトを、全4象限の対称ピーク到達後にロックする適応包絡線トラッカで正規化したうえで整数 CORDIC `atan2` により高精度角度へ変換します。
4. **熱雑音耐性付き静止復帰アンカー ＆ 物理24溝と 1:1 対応する `24 notches/rev` 出力**:
   * 熱雑音（$\pm 1\sim 2\,\text{LSB}$）に惑わされない静止監視アンカー（`CURCUR40_WHEEL_IDLE_NOISE_LSB = 5`）とデッドバンドヒステリシス（`12 LSB`）により、停止後 $60\,\text{ms}$ で確実に端数をクリアして放置時や中クリック時の誤発火を防止しつつ、回転中は **`WHEEL_NOTCHES_PER_REV = 24`**（物理24フルート溝と完全 1:1 同期）で滑らかにスクロール出力します（`WHL_HRZ` キー押下中はファームウェア側で水平スクロール `H-Wheel` へ自動切替。`Shift` キー押下時の挙動は OS／アプリ標準の `Shift + 縦スクロール` に委ねており、キー配置は Vial / VIA で自由に変更可能）。
