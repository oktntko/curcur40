# アンダープレート一体軸パッシブ磁気慣性ホイール 設計仕様書

本書は、電磁クラッチ（ソレノイド・コイル・駆動回路）や専用サブ基板・手配線ハーネス・接着剤・シムリング・スナップカバーを一切使わずに、**「1ピース一体軸 `45# Steel` CNC フライホイール（$\varnothing 22.00 \times 4.40\,\text{mm}$, $13.12\,\text{g}$） × 脱脂 `DDL-520ZZ` ミニチュアベアリング × 接着剤ゼロの24溝非接触磁気デテント × 右メイン基板 PCBA 直実装 3Dホールセンサー（`TMAG5273`）」** によって、**『普段は心地よい24ノッチ感があり、指で弾けば大慣性（$J \approx 790\,\text{g}\cdot\text{mm}^2$）で数秒間回り続け、指で触れれば瞬時にピタッと止まる』** 高速慣性スクロール＆静音ミドルクリックを実現するハードウェア・ファームウェア設計仕様書です。

---

## 1. 第一原理からの設計思想（複雑さの徹底排除）

従来の自作キーボード用ホイール機構で発生しがちだった「部品点数の肥大化・接着剥がれ・シム調整・極細線の断線・カバー干渉」を第一原理から見直し、以下のゼロベース統合アーキテクチャを採用しています。

| 設計課題 | 旧来のアプローチで起きやすい無理 | 本設計（アンダープレート一体軸方式）の解決策 |
| :--- | :--- | :--- |
| **① 軸・シム・同軸度** | 別体平行ピン＋オープン軸受＋極薄シムリング重ね | **`steel-flywheel.step` に $\varnothing 2.90\,\text{mm}$ 内輪当たり段付き肩・$\varnothing 1.98\,\text{mm}$ ジャーナル・西Dカット軸を1ピース一体切削**。標準両シールド **`DDL-520ZZ`（幅 $2.30\,\text{mm}$）** をそのまま挿すだけでシムリング完全不要。 |
| **② 慣性モーメントと低背化の両立** | プレート上に軸を置くと小径化するか背が高くなる | テンティングケース内の深い空間（$Z \approx -21\,\text{mm}$）を活かし、回転軸をプレート下 **$Z = -6.90\,\text{mm}$** に配置。外径 **$\varnothing 22.00\,\text{mm}$・質量 $13.12\,\text{g}$（$J \approx 790\,\text{g}\cdot\text{mm}^2$）** の大慣性を確保しつつ、ホイール頂点 **$Z = +4.10\,\text{mm}$（Choc V2 キー天面 $+3.60\,\text{mm}$ 比わずか $+0.50\,\text{mm}$）** の超低背を実現。 |
| **③ センサー基板と手配線** | 同軸対向のために極小サブ基板を垂直立て＋6芯手配線 | 右メイン基板 `B.Cu` のホイール窓横に **3軸リニアホールIC `rU6`（`TMAG5273A1QDBVR`, PCBA自動実装）** を配置し、軸端横（off-axis）から回転磁界 $(B_x, B_z)$ を直接ベクトル復調。**サブ基板・JST SH コネクタ・手配線ケーブルを完全ゼロ化**。 |
| **④ 磁気ラチェット構造** | 非磁性ホイール＋別体樹脂ハブ＋磁性鋼球多数 | ホイール自体を **強磁性炭素鋼 `45# Steel`（S45C）＋無電解ニッケルめっき** で製作し、外周の **24本の丸溝（$15^\circ$ ピッチ）** を指掛けローレット兼・磁気ラチェット歯として共用。別体ハブも鋼球もゼロ。 |
| **⑤ 磁石固定と接着剤排除** | 回転軸端やイモネジ先端への瞬間接着剤点付け | 角度磁石（`D4×1mm` 径方向着磁）は `magnet-holder.step` のポケットへ入れ軸端と基板窓で機械的抜け止め。ラチェット磁石（`NE280` $\varnothing 2\times 2\,\text{mm}$）は **鉄製 `M2×6.0mm` 調整ネジ先端に自己磁力で吸着**。**接着剤完全ゼロ**。 |
| **⑥ 外装カバーとプレート開口** | 軸受・基板を隠すスナップカバーと複雑な段付き窓 | 軸受・マグネットホルダー・ロッカー・センサーがすべてトッププレート下面（$Z = -3.60\,\text{mm}$）より下に収まるため、**トッププレート開口は $5.60 \times 22.00\,\text{mm}$ の角丸長穴1つだけ**。スナップカバー不要で外観も組立も極めてクリーン。 |

### 2.1 座標系定義（回転軸中心ローカル座標 $(u, v, w)$ ⇔ グローバル座標）
右手メイン基板上のホイール回転軸中心 **$(x_{\text{pcb}}, y_{\text{pcb}}) = (14.2875, -2.0000)\,\text{mm}$**（フルアセンブリ STEP 座標 **$(X_{\text{step}}, Y_{\text{step}}, Z_{\text{step}}) = (+28.5750, -55.1500, -6.9000)\,\text{mm}$**）を原点 $(u, v, w) = (0, 0, 0)$ とする平行移動座標系で定義します：
* **$u = x_{\text{pcb}} - 14.2875$**（$+u$: 東＝キーマトリクス側、$-u$: 西＝キーボード内側）
* **$v = -(y_{\text{pcb}} + 2.0000)$**（$+v$: 北＝PC側USBポート方向、$-v$: 南＝親指トラックボール方向）
* **$w = Z_{\text{step}} - (-6.9000)$**（メイン基板 `B.Cu`: $w = +1.10$ / `F.Cu`: $w = +2.70$、トッププレート: $w \in [+3.30, +4.90]$）

### 2.2 4つの製造パーツ詳細仕様（[`cases/inertia_wheel/`](../cases/inertia_wheel/)）

1. **`#01` 1ピース一体軸スチールホイール（[`steel-flywheel.step`](../cases/inertia_wheel/steel-flywheel.step) — JLCCNC `45# Steel` + 無電解ニッケルめっき）**:
   * **外周リム**: 外径 **$\varnothing 22.00\,\text{mm}$** × 幅 **$4.40\,\text{mm}$**（$u \in [-2.20, +2.20]\,\text{mm}$）。外周に半径 $R = 1.00\,\text{mm}$ の丸溝フルートを **$15^\circ$ ピッチで 24本** 加工（指先のグリップと強磁性24ノッチ磁気デテント極を兼用）。
   * **一体内輪ショルダー**: $u \in [-2.45, -2.20]$ および $[+2.20, +2.45]\,\text{mm}$ に外径 **$\varnothing 2.90\,\text{mm}$** の段付き肩を一体旋削。`DDL-520ZZ` の内輪端面（外径 $\approx \varnothing 2.9\text{〜}3.0\,\text{mm}$）のみに当接し、外輪・シールド（内径 $\approx \varnothing 4.0\,\text{mm}$）には一切擦れずに左右位置を完全拘束します（シムリングゼロ）。
   * **一体ベアリングジャーナル ＆ 西側Dカット軸**: $u \in [-6.90, +4.72]\,\text{mm}$（全長 $11.62\,\text{mm}$）の **$\varnothing 1.98\,\text{mm}$** 一体軸。東端 $+4.72\,\text{mm}$ は東ベアリング外端（$+4.75\,\text{mm}$）より $0.03\,\text{mm}$ 内側へ退避させてロッカー壁との接触を防止し、西端 $u \in [-6.90, -5.80]\,\text{mm}$ には回り止め Dカット平面（深さ $0.28\,\text{mm}$）を設けています。
   * **質量・回転慣性**: 質量 **$13.12\,\text{g}$**、軸回り慣性モーメント **$J \approx 790\,\text{g}\cdot\text{mm}^2$**（小径カップホイールの約3倍以上の純物理慣性）。

2. **`#02` 接着剤ゼロ マグネットホルダー（[`magnet-holder.step`](../cases/inertia_wheel/magnet-holder.step) — JLC3DP MJF/SLS PA12）**:
   * 外径 **$\varnothing 5.68\,\text{mm}$** × 長さ **$2.05\,\text{mm}$**（$u \in [-7.97, -5.92]\,\text{mm}$、JLC3DP MJF/SLS 最小造形基準 $5 \times 5 \times 2\,\text{mm}$ 適合、ポケット外周肉厚 $0.82\,\text{mm} \ge 0.80\,\text{mm}$）。
   * 東側（$u \in [-6.92, -5.92]$）の Dカット穴（$\varnothing 2.02\,\text{mm}$）を `#01` 西側Dカット軸へ差し込み、西側（$u \in [-7.97, -6.92]$）の **$\varnothing 4.04 \times$ 深さ $1.05\,\text{mm}$ ポケット** に `#08` `D4×1mm` 径方向2極着磁磁石を収めます。磁石は東側を鋼製D軸端面（$u = -6.90$）に自己吸着し、西側を右メイン基板窓端面（$u = -8.2875$、隙間 $0.34\,\text{mm}$）で機械的に抜け止めされるため、**接着剤なしで絶対に脱落しません**。

3. **`#03` シーソーロッカー（[`wheel-rocker.step`](../cases/inertia_wheel/wheel-rocker.step) — JLC3DP MJF/SLS PA12）**:
   * 外形 $22.15 \times 20.65 \times 14.35\,\text{mm}$。左右の上開き $\varnothing 5.04\,\text{mm}$ U字軸受座（$u \in [-4.75, -2.45]$ ＆ $[+2.45, +4.75]$）に脱脂した **NMB `DDL-520ZZ`（$\varnothing 2 \times \varnothing 5 \times 2.30\,\text{mm}$）× 2個** を受けます。
   * **一体トラニオン支点軸と中クリックてこ比**: $(u_{\text{piv}}, w_{\text{piv}}) = (-6.95, -0.65)\,\text{mm}$（$Z = -7.55\,\text{mm}$）に南北一対の一体成形 **$\varnothing 2.70\,\text{mm}$ トラニオン円筒軸** を備えます。ホイール押下荷重点（$u = 0.00 \rightarrow L_{\text{east}} = 6.95\,\text{mm}$）から支点を挟んで西側ストライカー（$u = -15.1375 \rightarrow L_{\text{west}} = 8.1875\,\text{mm}$）が基板裏面の静音スイッチ `rEXSW1`（作動力 $80\,\text{gf}$）を下から押し上げるシーソー構造により、指先クリック荷重 **約 $68\,\text{gf}$**（押下角 $2.20^\circ$・ホイール沈み量 $0.26\,\text{mm}$）の軽快で歯切れのよい静音ミドルクリックを実現します（別体の金属ヒンジピンも不要）。
   * **南側 接着剤ゼロ磁気デテント調整ボス**: 南側下部（$w = -4.40 \Leftrightarrow Z = -11.30\,\text{mm}$, $v \in [-16.40, -11.40]\,\text{mm}$）に $\varnothing 2.85\,\text{mm}$ 水平貫通穴を備え、南口（$v = -16.40$）に `M2×L3.0` 真鍮インサートを熱圧入します。南からねじ込む鉄製 `M2×6.0mm` ネジ先端に `#09` $\varnothing 2.0 \times 2.0\,\text{mm}$ ネオジム磁石（`NE280`）が自己吸着し、`45# Steel` ホイール外周24溝（$v = -10.08\,\text{mm}$）とのギャップ調整だけで **無抵抗フリースピン〜明快な24ノッチ感** を自在に無段階チューニングできます。

4. **`#04` アンダーPCBクレードル（[`wheel-cradle.step`](../cases/inertia_wheel/wheel-cradle.step) — JLC3DP MJF/SLS PA12）**:
   * 外形 $19.45 \times 24.30 \times 8.10\,\text{mm}$（$Z = -13.90 \sim -5.80\,\text{mm}$）。対角2箇所（`WC1`, `WC2`）の $\varnothing 2.85\,\text{mm}$ ボスに `M2×L3.0` 真鍮インサートを圧入し、右メイン基板 `F.Cu` から統一 `M2×6.0mm` ネジ2本で固定します。
   * 左右の上開き $\varnothing 3.10\,\text{mm}$ U字サドルとメイン基板裏面 `B.Cu`（$Z = -5.80\,\text{mm}$）で `#03` ロッカーの $\varnothing 2.70\,\text{mm}$ トラニオン支点軸を上下から挟み込んで保持するとともに、西端のストッパーブリッジ（$Z = -13.90 \sim -12.45\,\text{mm}$）がロッカー西アームの戻り位置（スイッチ予圧ゼロの静止位置）を正確に受け止めます。

## 3. オンボード 3D ホール磁気センシング ＆ ファームウェア信号処理

### 3.1 Off-Axis 2成分磁気ベクトル検出原理
* 回転軸西端の `D4×1mm` 径方向2極着磁磁石が1回転すると、その西側 $2.78\,\text{mm}$ にある右メイン基板 `B.Cu` 上の 3軸リニアホールセンサー **`rU6`（`TMAG5273A1QDBVR`）** 位置では、基板水平成分 $B_x$（ダイポール軸方向で振幅約2倍）と基板法線成分 $B_z$ が互いに $90^\circ$ 位相のずれた正弦波・余弦波として回転します。
* これにより、磁石の軸延長線上に別基板を垂直に立てる必要が一切なく、メイン基板裏面の SMD IC 1個だけで $0^\circ \sim 360^\circ$ の絶対回転角を非接触で連続復調できます。

### 3.2 高速フリック対応 QMK / Vial ドライバ（[`curcur40_scroll.c`](../kbd_firmware/keyboards/curcur40/qmk/qmk_firmware/rev1/curcur40_scroll.c)）
1. **デュアルセンサー自動プローブ（`TMAG5273` ＆ `TLV493D-A1B6` 両対応）**:
   * 起動時およびバスリカバリ時に `I2C0`（`GP24`/`GP25`, `400 kHz`）上で TI `TMAG5273`（A1:`0x35`, B1:`0x22`, C1:`0x78`, D1:`0x44`）を優先検出し、未検出時はピン互換の Infineon `TLV493D-A1B6`（`0x5E`, `0x1F`）へ自動フォールバックします。
2. **`XZX` 擬似同時サンプリングによる高速スピン位相スキュー除去（`TMAG5273`）**:
   * `TMAG5273` を連続変換モード（`CONV_AVG = 4x` $\approx 950\,\text{Hz}$、感度レンジ `±40 mT` / `±80 mT`）かつ **`MAG_CH_EN = XZX` モード** で駆動します。チップ内部で `X1 → Z → X2` の順にAD変換し $(X_1 + X_2)/2$ と $Z$ の時刻重心を完全一致させるため、指で強く弾いた **毎分千回転クラスの高速フリースピン中でも角度位相遅れが発生しません**。
3. **適応型 Max/Min 包絡線正規化 ＋ 16-bit 整数 CORDIC `atan2`**:
   * Off-axis 配置特有の $B_x$・$B_z$ 振幅比（約 $2:1$）および磁石個体差・温度ドリフトを、実行時の指数減衰付き適応包絡線トラッカで正規化したうえで 16-bit 整数 `atan2` により高精度角度へ変換します。
4. **物理24溝と 1:1 対応する `24 notches/rev` 出力**:
   * デッドバンドヒステリシスで静止時の微小ノイズを遮断しつつ、端数アキュムレータにより **`WHEEL_NOTCHES_PER_REV = 24`**（物理24フルート溝と完全 1:1 同期）で滑らかにスクロール出力します（`Shift` または `WHL_HRZ` キー押下中は水平スクロールへ自動切替）。
