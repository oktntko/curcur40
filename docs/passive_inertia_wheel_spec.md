# アンダープレート一体軸パッシブ磁気慣性ホイール 設計仕様書

本書は、電磁クラッチ（ソレノイド・コイル・駆動回路）や専用サブ基板・手配線ハーネス・接着剤・シムリング・スナップカバーを一切使わずに、**「1ピース一体軸 `45# Steel` CNC フライホイール（$\varnothing 22.00 \times 6.50\,\text{mm}$, $18.56\,\text{g}$） × 脱脂 `DDL-520ZZ` ミニチュアベアリング × 接着剤ゼロ・抜け止め付きの深溝24極磁気デテント × 右メイン基板 PCBA 直実装 3Dホールセンサー（`TMAG5273`）」** によって、**『普段は心地よい24ノッチ感があり、指で弾けば大慣性（$J \approx 1056\,\text{g}\cdot\text{mm}^2$）で数秒間回り続け、指で触れれば瞬時にピタッと止まる』** 高速慣性スクロール＆静音ミドルクリックを実現するハードウェア・ファームウェア設計仕様書です。

### 0.1 高速スクロールのしくみと `#02 マグネットホルダー` の場所（「重い鉄のコマ × 空中コンパス」）
* **なぜ一度はじくと「シューーーッ！」と長く回り続けるの？**
  軽いプラスチックではなく、**幅 $6.50\,\text{mm}$・重さ $18.56\,\text{g}$（10円玉4枚分以上のズッシリ感！）** の「`#01` 鉄のコマ」を、2個のミニチュアベアリング（`#07`）で支えているからです。自転車の車輪と同じで、指ではじけば重さの勢い（慣性）で何秒も回り続け、止めたいときは指先で軽く触れるだけでその瞬間にピタッと止まります。
* **`#02 マグネットホルダー` はどこで何をしているの？**
  `#01` 鉄のコマから右（東・キーマトリクス側）へ伸びた「かまぼこ型（Dカット）の鉄の軸」の先端にスポッと刺さっている**小さな丸いキャップが `#02 マグネットホルダー`** です。中に **`#08` 赤青2極磁石（N極・S極）** を入れて軸と一緒にくるくる回します。左側は鉄の軸の段差、右側は `#03` ロッカーから立ち上がる **「抜け止め壁（キーパータブ）」** に挟まれているため、**接着剤ゼロでも絶対に抜け落ちません**。
* **どうやって回転を読み取っているの？（こすれゼロ！）**
  右メイン基板の裏面に最初から付いている **`#05` 空中コンパス（3D磁気センサー `rU6: TMAG5273`）** が、`#08` 磁石に一切触れずに空中から「いま磁石が何時の方角を向いているか」を毎秒約1,000回キャッチします。こすれる部品がゼロなのでブレーキがかかりません。

### 0.2 ノッチ（カリカリ感）調整のしくみ（「24個の鉄の山 × 磁石つきネジの距離あそび」）
* **`#01` 鉄のコマの外周には 24個の「山」と「谷」** が彫られています。そのすぐ南側（親指側）のトンネル（`#03` 南ボス＋`#10` 真鍮インサート）に **`#11` 鉄のネジ** をねじ込み、ネジの先端に **`#09` 小さな磁石** を磁力でパチンとくっつけます（ボンド不要！）。
* 磁石は遠い「谷」より近い「山」を強く引っ張るため、コマが回るたびに山から山へ **1周24回の「カチ・カチ・カチ！」という気持ちいいノッチ感** が生まれます。
* **ドライバー1本で好みの重さにチューニング可能！（基板へのネジ止め前に調整）**:
  * **ネジを右へ回して磁石を近づける** → 磁力が強まり「カチカチ！」としっかり止まる24ノッチモード（最奥まで締めても北端の抜け止め顎が磁石を確実にストップするため、ホイールに磁石が張り付く心配はゼロ！）
  * **ネジを左へ回して磁石を遠ざける** → 磁力がフワッと弱まり、引っかかりゼロの「ツルツル無限スピン」モード
  * 空中の磁力で引っ張っているだけなので、プラスチックのツメやバネと違って **何万回まわしても一生すり減りません**（※調整ネジは右メイン基板の下に収まるため、右メイン基板へ `WC1`/`WC2` ネジで固定する前の単体状態で好みの感触へ合わせておきます）。

### 0.3 背面スイッチへのミドルクリックのしくみ（「パチンと連結したCクリップ支点のシーソーで基板ウラの赤いボタンを下からポチッ！」）
* ホイールを支えている `#03 シーソーロッカー` は、文字どおり **「公園のシーソー」** になっています。
* 真ん中の丸い支点棒（直径 $\varnothing 3.00\,\text{mm}$）は、`#04 クレードル` の **「スリット分離型Cクリップ軸受け（抱き角 $220^\circ$・上開口 $2.78\,\text{mm}$）」** に上から **「パチン！」と弾性スナップイン連結** されます。だから基板にネジ止めする前の単体状態でも上にも横にも抜け落ちず、回転（シーソー運動）だけができる安心の機械ヒンジになっています。
* 指でシーソーの左側（`#01` ホイール）を下にグッと押すと（わずか $0.31\,\text{mm}$ 沈むだけ）、支点の反対側にある北東うでが **「上」に向かって持ち上がり**、基板の裏に逆さまに付いた **`#06` 静音スイッチ (`rEXSW1`) の黄色いボタンを下からポチッ！** と押します。
* 支点からホイール側（$6.10\,\text{mm}$）とスイッチ側（$4.91\,\text{mm}$）のてこ比により、約 **$55\,\text{gf}$** の歯切れよい力で静かにミドルクリックでき、手を離せば `#04` の「やすみ台（東側戻りストッパー）」でピタッと静止します。

## 1. 第一原理からの設計思想（複雑さの徹底排除）

従来の自作キーボード用ホイール機構で発生しがちだった「部品点数の肥大化・接着剥がれ・シム調整・極細線の断線・カバー干渉・ガタつき」を第一原理から見直し、以下のゼロベース統合アーキテクチャを採用しています。

| 設計課題 | 旧来のアプローチで起きやすい無理 | 本設計（アンダープレート一体軸方式）の解決策 |
| :--- | :--- | :--- |
| **① 軸・シム・同軸度** | 別体平行ピン＋オープン軸受＋極薄シムリング重ね | **`steel-flywheel.step` に $\varnothing 2.90\,\text{mm}$ 内輪当たり段付き肩・$\varnothing 1.98\,\text{mm}$ ジャーナル・東Dカット軸を1ピース一体切削**。標準両シールド **`DDL-520ZZ`（幅 $2.30\,\text{mm}$）** を挿し、`#03` の **Cクリップスナップ軸受座** へパチンと嵌めるだけでシムリング不要・上抜けゼロ。 |
| **② 大慣性と幅広操作感・低背化の両立** | 細いホイールは指掛かりが薄く、軸を上に出すと背が高くなる | テンティングケース内の深い空間（$Z \approx -30\,\text{mm}$）を活かし、回転軸をプレート下 **$Z = -6.90\,\text{mm}$** に配置。**外径 $\varnothing 22.00\,\text{mm}$ × 幅 $6.50\,\text{mm}$・質量 $18.56\,\text{g}$（$J = 1056\,\text{g}\cdot\text{mm}^2$）** の幅広・大慣性を確保しつつ、頂点 **$Z = +4.10\,\text{mm}$（キー天面比わずか $+0.50\,\text{mm}$）** の超低背を実現。 |
| **③ センサー基板と手配線** | 同軸対向のために極小サブ基板を垂直立て＋6芯手配線 | 右メイン基板 `B.Cu` のホイール窓東横に **3軸リニアホールIC `rU6`（`TMAG5273A1QDBVR`, PCBA自動実装）** を配置し、軸端正面横（off-axis）から回転磁界 $(B_x, B_z)$ を直接ベクトル復調。**サブ基板・JST SH コネクタ・手配線ケーブルを完全ゼロ化**。 |
| **④ 磁気ラチェット構造** | 非磁性ホイール＋別体樹脂ハブ＋磁性鋼球多数 | ホイール自体を **強磁性炭素鋼 `45# Steel`（S45C）＋無電解ニッケルめっき** で製作し、外周の **24本の丸溝（$15^\circ$ ピッチ）** を指掛けローレット兼・磁気ラチェット歯として共用。別体ハブも鋼球もゼロ。 |
| **⑤ 磁石固定と接着剤排除** | 回転軸端やイモネジ先端への瞬間接着剤点付け | 角度磁石（`#08` `D4×1mm` 径方向着磁）は **`#02` マグネットホルダー** に入れ `#01` 軸段差と **`#03` 東一体キーパータブ** で両方向ロック。ラチェット磁石（`#09` `NE280`）は **鉄製 `M2×6.0mm` ネジ先端に自己磁力で吸着**。**接着剤完全ゼロ**。 |
| **⑥ 外装カバーとプレート固定** | 軸受・基板を隠す別体スナップカバーや外周の目立つネジ穴 | 機構全体がトッププレート下面（$Z = -3.60\,\text{mm}$）より下に収まるため、**トッププレート開口は $8.05 \times 22.00\,\text{mm}$ の角丸長穴1つだけ**。キー谷間12箇所のコンパクト $\varnothing 5.20\,\text{mm}$ フラットボス（外周むき出し穴ゼロ）でメイン基板を直接ネジ固定し、ネジ頭はプレート $\varnothing 4.40\,\text{mm}$ 穴下に沈み込み、プレートは 39個の Choc V2 スイッチ嵌合で保持。 |

### 2.1 座標系定義（回転軸中心ローカル座標 $(u, v, w)$ ⇔ グローバル座標）
右手メイン基板上のホイール回転軸中心 **$(x_{\text{pcb}}, y_{\text{pcb}}) = (14.2875, +2.7625)\,\text{mm}$**（南側隣接キー `rEXSW2` $(14.2875, 23.8125)$ と左右中心軸が **`0.0000 mm` 誤差で完全一致**、フルアセンブリ STEP 座標 **$(X_{\text{step}}, Y_{\text{step}}, Z_{\text{step}}) = (+28.5750, -59.9125, -6.9000)\,\text{mm}$**）を原点 $(u, v, w) = (0, 0, 0)$ とする平行移動座標系で定義します：
* **$u = x_{\text{pcb}} - 14.2875$**（$+u$: 東＝キーマトリクス・支点・`rU6`/`rEXSW1` 側、$-u$: 西＝キーボード内側・西壁張り出しゼロ）
* **$v = -(y_{\text{pcb}} - 2.7625)$**（$+v$: 北＝PC側USBポート方向、$-v$: 南＝親指トラックボール方向）
* **$w = Z_{\text{step}} - (-6.9000)$**（メイン基板 `B.Cu`: $w = +1.10$ / `F.Cu`: $w = +2.70$、トッププレート: $w \in [+3.30, +4.90]$）

### 2.2 4つの製造パーツ詳細仕様（[`cases/inertia_wheel/`](../cases/inertia_wheel/)）

1. **`#01` 1ピース一体軸スチールホイール（[`steel-flywheel.step`](../cases/inertia_wheel/steel-flywheel.step) — JLCCNC `45# Steel` + 無電解ニッケルめっき）**:
   * **外周リム**: 外径 **$\varnothing 22.00\,\text{mm}$** × **幅 $6.50\,\text{mm}$**（$u \in [-3.25, +3.25]\,\text{mm}$）。外周に半径 $R = 0.90\,\text{mm}$・深さ **$0.65\,\text{mm}$** の深溝フルートを **$15^\circ$ ピッチで 24本** 加工（指先のゆとりあるグリップ幅と明快な強磁性24ノッチ磁気デテント極を兼用）。
   * **一体内輪ショルダー**: $u \in [-3.45, -3.25]$ および $[+3.25, +3.45]\,\text{mm}$ に外径 **$\varnothing 2.90\,\text{mm}$** の段付き肩を一体旋削。`DDL-520ZZ` の内輪端面（外径 $\approx \varnothing 2.9\text{〜}3.0\,\text{mm}$）のみに当接し、外輪・シールドには一切擦れずに左右位置を拘束します（シムリングゼロ）。
   * **一体ベアリングジャーナル ＆ 東側Dカット軸**: $u \in [-5.72, +8.03]\,\text{mm}$（全長 $13.75\,\text{mm}$）の **$\varnothing 1.98\,\text{mm}$** 一体軸（JLCCNC 発注時は `DDL-520ZZ` 内径 $\varnothing 2.000\,\text{mm}$ との精密はめあいのため **めっき後仕上がり軸径 $\varnothing 1.990 \pm 0.010\,\text{mm}$［`h6`〜`g6` 精密公差］** を指定）。西端 $-5.72\,\text{mm}$ は西ベアリング外端（$-5.75\,\text{mm}$）より $0.03\,\text{mm}$ 内側へ退避させてロッカー壁との接触を防止し、東端 $u \in [+6.75, +8.03]\,\text{mm}$（長さ $1.28\,\text{mm}$）に回り止め Dカット平面（$w \ge +0.70\,\text{mm}$ 除去、$-u$ 側ストッパー段差 $u = +6.75\,\text{mm}$）を設けています。
   * **質量・回転慣性**: 体積 $2364.4\,\text{mm}^3$、質量 **$18.56\,\text{g}$**、軸回り慣性モーメント **$J = 1056\,\text{g}\cdot\text{mm}^2$**（S45C 鉄損・渦電流損・脱脂軸受摩擦込みで指フリックから $3\sim 5\,\text{秒}$ 空転する大慣性）。

2. **`#02` 接着剤ゼロ マグネットホルダー（[`magnet-holder.step`](../cases/inertia_wheel/magnet-holder.step) — JLC3DP MJF/SLS PA12）**:
   * 外径 **$\varnothing 5.65\,\text{mm}$** × 長さ **$2.28\,\text{mm}$**（$u \in [+6.77, +9.05]\,\text{mm}$、JLC3DP MJF/SLS 最小造形基準適合、ポケット外周肉厚 $0.81\,\text{mm} \ge 0.80\,\text{mm}$、$2.95^\circ$ フルクリック時もプレート下面と $\ge 0.33\,\text{mm}$ 非接触）。
   * 西側（$u \in [+6.77, +8.05]$、嵌合長 **$1.28\,\text{mm}$**）のタイトな Dカット穴（$\varnothing 1.99\,\text{mm}$, D平面 $w = +0.71\,\text{mm}$）を `#01` 東側Dカット軸へ圧入し、西端は軸の Dカット段差（$u = +6.75$）で位置決めされます。東側（$u \in [+8.05, +9.05]$）の **$\varnothing 4.03 \times$ 深さ $1.00\,\text{mm}$ ポケット** に `#08` `D4×1mm` 径方向2極着磁磁石を収納し、東側は `#03` ロッカーの一体成形 **キーパータブ（$u \in [+9.30, +10.30]$、クリアランス $0.25\,\text{mm}$）** が機械的に抜け止めするため、**接着剤なしで `#02` も `#08` も絶対に脱落しません**。

3. **`#03` シーソーロッカー（[`wheel-rocker.step`](../cases/inertia_wheel/wheel-rocker.step) — JLC3DP MJF/SLS PA12）**:
   * 外形 $18.97 \times 28.22 \times 14.45\,\text{mm}$。左右耳（$u \in [-6.62, -3.55]$ ＆ $[+3.55, +6.56]$）の $\varnothing 5.04\,\text{mm}$ 軸受座は、上半の爪を端壁から切り離した **独立片持ち弾性 Cクリップ（上開口幅 $4.78\,\text{mm}$、圧入時ひずみ $\approx 2.0\% < 3.5\%$ 弾性限）** と下半の端壁ストッパーを組み合わせており、PA12 爪に無理なせん断ひずみをかけずに脱脂 **`DDL-520ZZ` × 2個** をパチンと保持します。
   * **一体 $\varnothing 3.00\,\text{mm}$ トラニオン支点軸・補強 $2.15\,\text{mm}$ アーム・西側過荷重ハードストップ**: $(u_{\text{piv}}, w_{\text{piv}}) = (+6.10, -4.65)\,\text{mm}$（グローバル $Z = -11.55\,\text{mm}$）に南北一対の一体成形 **$\varnothing 3.00\,\text{mm}$ トラニオン円筒軸** を備え、`#04` クレードルの **Cクリップスナップイン軸受** へ機械連結されます。剛性を高めた **厚さ $2.15\,\text{mm}$** の北東ストライカー腕（$u = +11.01\,\text{mm}, v = +7.51\,\text{mm}$）が静音スイッチ `rEXSW1`（`B.Cu` $(25.30, -4.75)$）を下から押し上げ、指先荷重 **約 $55\,\text{gf}$** の歯切れよい静音ミドルクリックを実現するとともに、スイッチ動作直後（約 $+3.15^\circ$）で西耳北面の **過荷重ストップノーズ（$u \in [-6.62, -4.50], v \in [+3.48, +5.15], w_{\text{bot}} = -3.20\,\text{mm}$）** が `#04` クレードル `WC1` ボス南側の **受け棚（$w_{\text{top}} = -3.90\,\text{mm}$）** に当接して強押し荷重を受け止め、`rEXSW1` を確実に保護します（メイン基板とのクリアランス $\ge 0.31\,\text{mm}$ も完全維持）。
   * **南側 抜け止め顎付き接着剤ゼロ磁気デテント調整ボス**: 南側下部（$w = -4.15 \Leftrightarrow Z = -11.05\,\text{mm}$, $v \in [-19.12, -11.12]\,\text{mm}$）は、①南端の $\varnothing 2.85\,\text{mm}$ 真鍮インサート穴（円錐導入部付）、②熱圧入後に上から `#09` 磁石を投入できる **後部ドロップイン窓（$v \in [-14.35, -12.20]$）**、③磁石の横ズレ・浮き上がりを防ぐ **密閉 $\varnothing 2.14\,\text{mm}$ ガイドトンネル**、および④ホイール下曲面に潜り込んで磁石の飛び出し・吸着を物理阻止する **北端下部抜け止め顎（厚さ $0.82\,\text{mm}$, $v \in [-11.12, -10.30]$）** を一体化しています。

4. **`#04` アンダーPCBクレードル（[`wheel-cradle.step`](../cases/inertia_wheel/wheel-cradle.step) — JLC3DP MJF/SLS PA12）**:
   * 外形 $18.75 \times 27.60 \times 11.30\,\text{mm}$（$Z = -17.10 \sim -5.80\,\text{mm}$）の **南開放 U字フレーム**（`WC1` 北西スパイン $\to$ 北アーチ $\to$ 北東コラム $\to$ 左右サドル＆下部ブリッジ $\to$ `WC2`）。南西側を開放していることで、`#03` ロッカーに `#01` ホイール・ベアリング・`#02` マグネットホルダーを組み込んだ状態のまま、引っ掛かりゼロで真上から垂直に Cクリップへ降ろすことができます。対角2箇所（`WC1 (7.3375, -5.0375)`, `WC2 (21.2375, 10.7625)`）のボスに `M2×L3.0` 真鍮インサートを圧入し、右メイン基板 `F.Cu` から統一 `M2×6.0mm` ネジ2本で締結した瞬間に基板 FR-4 と閉じた高剛性ボックス構造を形成します。
   * **スリット分離型 Cクリップスナップイン機械連結ヒンジ**: 奥壁との間に幅 **$0.93\,\text{mm} \ge 0.80\,\text{mm}$ の逃げスリット** を設けて独立片持ち梁化した左右対称の **$\varnothing 3.06\,\text{mm}$ Cクリップ軸受サドル**（上開口スロート幅 **$2.78\,\text{mm}$**、抱き角 **$220^\circ$**、圧入時ひずみ **$\approx 2.1\% < 3.5\%$ 弾性限**）へ `#03` の $\varnothing 3.00\,\text{mm}$ トラニオン支点軸を上から「パチン！」と弾性スナップインさせることで、**メイン基板に組み付ける前の `#03`＋`#04` 単体状態でも `±u, ±v, +w, -w` 全方向に抜け落ちず一体連結** されます。さらに東端の戻りストッパーブリッジがスイッチ予圧ゼロの静止位置を正確に受け止めます。

### 2.3 固定自由度・稼働自由度（6-DOF）および垂直挿入軌道の自動検証 (`verify_6dof_constraints`)
単純な「静止時の干渉ゼロ・クリアランス確保」だけでなく、**「固定されるべき自由度が機械的ストッパーで確実にロックされ、稼働すべき自由度および組み立て時の垂直挿入軌道が干渉ゼロで通ること」** を [`scripts/generate_inertia_wheel.py`](../scripts/generate_inertia_wheel.py) および [`scripts/generate_full_assembly.py`](../scripts/generate_full_assembly.py) 内で自動アサート検証しています：
1. **ホイール回転自由度 (`Rx` $0^\circ \sim 360^\circ$)**: 全回転角で全周辺部品との干渉体積 `0.00000000 mm³`。
2. **ベアリング＆ホイール 5自由度ロック**: `#03` 分離型Cクリップ座（開口 $4.78\,\text{mm}$）と `#01` 内輪段付き肩により、`±u, ±v, -w` および上方向 `+w`（最大浮き $\le 0.060\,\text{mm}$ で機械的ストッパー接触 `overlap_volume > 0`）を完全拘束。
3. **`#02` マグネットホルダー＆`#08` 磁石・`#09` デテント磁石ロック**: `#01` Dカット軸段差（`-u` ＆軸回り相対回転）と `#03` 東キーパータブ（`+u`、クリアランス $0.25\,\text{mm}$）、および密閉 $\varnothing 2.14\,\text{mm}$ トンネル＋北端抜け止め顎により全方向抜け止めを自動確認。
4. **`#03` Cクリップスナップイン支点＆クリック運動・過荷重ストップ**: **基板なしの `#04` クレードル単体に対して `±u, ±v, +w, -w` すべて機械ロック** され、`+2.95°` 押下時に `rEXSW1` プランジャのみを確実に押し込み（他部品干渉 `0.00000000 mm³`）、`+3.25°` までに西側ストップノーズが `#04` クレードル受け棚へ確実に当接し、逆方向（ホイール持ち上げ `-1.50°`）も `#04` 東ストッパーが即時阻止。
5. **垂直組み込み軌道（Top-Down Insertion Trajectory）無干渉検証**: ローター一式 $\to$ `#03` ロッカー、およびローター組込済み `#03` ロッカー $\to$ `#04` 南開放 U字クレードルの垂直降下軌道（$dw = +15.0 \to 0.0\,\text{mm}$）で剛体引っ掛かり `0.00000000 mm³` を自動確認。

## 3. オンボード 3D ホール磁気センシング ＆ ファームウェア信号処理

### 3.1 Off-Axis 2成分磁気ベクトル検出原理
* 回転軸東端の `D4×1mm` 径方向2極着磁磁石が1回転すると、その東側にある右メイン基板 `B.Cu` 上の 3軸リニアホールセンサー **`rU6`（`TMAG5273A1QDBVR`）** 位置では、基板水平成分 $B_x$ と基板法線成分 $B_z$ が互いに $90^\circ$ 位相のずれた正弦波・余弦波として回転します。
* これにより、磁石の軸延長線上に別基板を垂直に立てる必要が一切なく、メイン基板裏面の SMD IC 1個だけで $0^\circ \sim 360^\circ$ の絶対回転角を非接触で連続復調できます。

### 3.2 高速フリック対応 QMK / Vial ドライバ（[`curcur40_scroll.c`](../kbd_firmware/keyboards/curcur40/qmk/qmk_firmware/rev1/curcur40_scroll.c)）
1. **デュアルセンサー自動プローブ（`TMAG5273` ＆ `TLV493D-A1B6` 両対応）**:
   * 起動時およびバスリカバリ時に `I2C0`（`GP24`/`GP25`, `400 kHz`）上で TI `TMAG5273`（A1:`0x35`, B1:`0x22`, C1:`0x78`, D1:`0x44`）を優先検出し、未検出時はピン互換の Infineon `TLV493D-A1B6`（`0x5E`, `0x1F`、右手系 X/Y 入替に伴う `(-By, -Bz)` 極性整合＆ `FRM` カウンタ凍結監視対応）へ自動フォールバックします。
2. **`XZX` 擬似同時サンプリングによる高速スピン位相スキュー除去（`TMAG5273`）**:
   * `TMAG5273` を低雑音連続変換モード（`CONV_AVG = 4x` $\approx 3.1\,\text{kSPS}$、感度レンジ `±80 mT`［`A2` 系は `±266 mT`］）かつ **`MAG_CH_EN = XZX` モード** で駆動します。チップ内部で `X1 → Z → X2` の順にAD変換し $(X_1 + X_2)/2$ と $Z$ の時刻重心を完全一致させるため、指で強く弾いた **毎分千回転クラスの高速フリースピン中でも角度位相遅れが発生しません**。
3. **4象限対称ロック付き適応型 Max/Min 包絡線正規化 ＋ 12-bit 整数 CORDIC `atan2`**:
   * Off-axis 配置の $B_x$・$B_z$ 振幅比（実測約 $1.08:1$：未1回転の起動直後から初期補正適用）および磁石個体差・温度ドリフトを、全4象限の対称ピーク到達後にロックする適応包絡線トラッカで正規化したうえで整数 CORDIC `atan2` により高精度角度へ変換します。
4. **熱雑音耐性付き静止復帰アンカー ＆ 物理24溝と 1:1 対応する `24 notches/rev` 出力**:
   * 熱雑音（$\pm 1\sim 2\,\text{LSB}$）に惑わされない静止監視アンカー（`CURCUR40_WHEEL_IDLE_NOISE_LSB = 5`）とデッドバンドヒステリシス（`12 LSB`）により、停止後 $60\,\text{ms}$ で確実に端数をクリアして放置時や中クリック時の誤発火を防止しつつ、回転中は **`WHEEL_NOTCHES_PER_REV = 24`**（物理24フルート溝と完全 1:1 同期）で滑らかにスクロール出力します（`WHL_HRZ` キー押下中はファームウェア側で水平スクロール `H-Wheel` へ自動切替。`Shift` キー押下時の挙動は OS／アプリ標準の `Shift + 縦スクロール` に委ねており、キー配置は Vial / VIA で自由に変更可能）。
