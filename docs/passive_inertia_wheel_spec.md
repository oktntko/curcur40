# パッシブ磁気慣性ホイールモジュール 設計仕様書（`curcur40-inertia-wheel`）

本書は、電磁クラッチ（ラチェット ⇔ フリースピン切替用のソレノイド・コイル・駆動回路）をあえて持たず、**「高比重ステンレス削り出しホイール × 脱脂ミニチュアベアリング × 渦電流ゼロの非接触磁気ラチェット」** のみによって **『普段は心地よいノッチ感があり、弾けば微振動を伴いながら慣性で回り続け、指で触れればピタッと止まる』** 高速スクロールホイールモジュールの Phase 1 確定設計仕様書です。

> [!IMPORTANT]
> **確定した基本設計方針（シンプル・高信頼・省スペース）**
> 1. **単体試作先行 → `curcur40-right` Rev2 統合**: まずは単体 USB-C デスクトップ試作機（`RP2040-Zero` キャリア基板 ＋ ホイールモジュール）として製作・調整し、その後 `curcur40-right` Rev2（基板外形・プレート・ケース変更なし、`+3.3V` ＆ `I2C` コネクタのみ追加）へそのまま組み込める構造とします。
> 2. **電磁アクチュエータ＆変換マイコン全廃**: ソレノイド・巻線コイル・Hブリッジドライバ・変換用サブマイコン・`+5V` 電源配線をすべて廃止し、クラッチ消費電流 **`0.0 mA`**・故障箇所最小の純パッシブ機構とします。
> 3. **シルバー金属外観 ＋ Oリング着脱 2way 対応（$\varnothing 16.8\,\text{mm}$ `SUS304`）**: 既存のトッププレート開口（`18.20 × 18.20 mm`）を無改造で通過する $\varnothing 16.80\,\text{mm}$ 非磁性ステンレス削り出しホイールとし、普段は金属むき出しで美しく使え、好みで市販Oリングも装着できる 2way 外周溝を設けます。
> 4. **静音ミドルクリック標準搭載（一体揺動キャリッジ）**: `Kailh Square Silent (6×6×4.3mm)` 静音スイッチを採用し、高速回転を指で止めた際に誤クリックせず、押し込み中も磁気ギャップが一切変化しない一体揺動構造とします。

## 2. コア機構設計（慣性・渦電流対策・磁力調整・静音クリック）

### 2.1 ホイール本体：`SUS304` シルバー削り出し（2way 外周仕上げ）
* **材質**: 非磁性オーステナイト系ステンレス **`SUS304`**（または `SUS316`、比重 **$7.93\,\text{g/cm}^3$**）。
  * アルミ（比重 $2.7$）の **約3倍の重さ**（単体質量 **約 $9.1\,\text{g}$**、樹脂製 `CKW12` ホイールの約8〜10倍の慣性モーメント $J \approx 330\,\text{g}\cdot\text{mm}^2$）を持ち、サビや変色が一切起きない上質なシルバー外観を維持します。
* **MX Master 3S 風「2way 外周プロファイル」**:
  * 外周（幅 $5.60\,\text{mm}$）には、金属むき出し（ゴムなし）の状態で指がしっかり掛かる **36本の浅い横溝（フルート加工）** と、中央を走る **幅 $1.30\,\text{mm} \times$ 深さ $0.50\,\text{mm}$ のセンターアクセント溝** を加工します。
  * **標準状態（金属むき出し）**: Logitech MX Master 3S のような精悍な削り出しシルバーホイールとしてそのまま機能します。
  * **高グリップ状態（オプション）**: センター溝に市販の極細シリコン／ニトリルOリング（内径 $\varnothing 15.0 \times$ 線径 $1.0\,\text{mm}$）をパチンと嵌めると、外周から $+0.5\,\text{mm}$ だけラバーが顔を出して指への吸い付きを強化でき、いつでも爪で着脱できます。

### 2.2 「渦電流ブレーキ完全ゼロ」の絶縁18球・磁気ラチェット構造
* **なぜ金属ホイールに直接磁石を当てないのか**:
  * 導電体である金属ホイール（や金属一体ギヤ）に強い磁石を直接近づけて高速回転させると、金属内部に渦電流が流れて強力な電磁ブレーキ（アラゴーの円盤現象）が発生し、1秒足らずで回転が止まってしまいます。
* **解決策（絶縁樹脂リング ＋ 独立 $\varnothing 1.0\,\text{mm}$ 鋼球 × 18個）**:
  * `SUS304` ホイール本体の東隣（$X = +3.2 \sim +5.2\,\text{mm}$）に、電気を一切通さない **3Dプリント SLA レジン製ラチェットハブ（外径 $\varnothing 10.80 \times$ 幅 $2.00\,\text{mm}$）** を同軸配置し、その外周の18箇所のくぼみに **市販の $\varnothing 1.00\,\text{mm}$ 精密鋼球（`SUJ2` ベアリング球）を18個（$20^\circ$ 刻み＝1周18ノッチ）** スナップイン圧入します。
  * 隣り合う鋼球同士が樹脂で完全に電気絶縁されており、かつ1粒が $\varnothing 1.0\,\text{mm}$ と極小なため、**高速回転時の渦電流損失が文字通りゼロ（$< 1\%$）** になります。
  * さらに球面同士の磁気吸引は滑らかな正弦波ポテンシャルを描くため、角張った歯車のような引っかかりがなく、**弾いたときに「トトトトト…」という心地よい微振動を伝えながら 3〜7秒間スーーッと伸びやかに回り続け**、回転が止まった瞬間も振動の消失で指先にすぐ分かります。

### 2.3 分解不要の「M2ネジ磁力（ノッチ感 ⇔ 空転伸び）無段階調整」
* インナーキャリッジ南東部に保持したラチェット用ネオジム磁石（$\varnothing 2.0 \times 1.5\,\text{mm}$, `N35`）の背面に、**M2 ステンレス調整ネジ（ピッチ $0.40\,\text{mm}$/回転）** を配置します。
* 組み立てた後からでも精密ドライバー／六角レンチ1本で磁石ギャップ $g$ を $0.15\,\text{mm} \sim 1.20\,\text{mm}$ の間で微調整できるため：
  * **ネジを少し締める（$g \approx 0.20\,\text{mm}$）**: 1ノッチごとのコリコリ感がはっきりした精密ラチェット寄り
  * **標準位置（$g \approx 0.35 \sim 0.45\,\text{mm}$）**: 適度なノッチ振動と 3〜7秒の気持ちよい慣性スピンの両立
  * **ネジを緩める（$g \ge 1.0\,\text{mm}$）**: ほぼ無抵抗のロングフリースピン
  を自分の指の感覚に合わせていつでも追い込めます。

### 2.4 静音ミドルクリック機構（スピン停止時の誤クリック防止設計）
* **一体揺動インナーキャリッジ**:
  * 北端ヒンジピン（$\varnothing 1.50\,\text{mm}$, $Y = -7.80\,\text{mm}$）を支点として、`{ホイール ＋ ベアリング2個 ＋ AS5600角度センサー ＋ 18球ラチェット＆調整磁石}` を載せた U字キャリッジ全体が一体で揺動します。
  * ミドルクリックを押し込んでも **磁石とロータ、および角度センサーの相対距離は $0.000\,\text{mm}$ もズレない** ため、クリック時の誤スクロールや部品接触が原理的に起きません。
* **静音マイクロスイッチ ＆ 誤爆防止レバー比**:
  * 南端（$Y = +6.60\,\text{mm}$）に静音角形マイクロスイッチ **`Kailh Square Silent Micro Switch (6.0 × 6.0 × 4.3 mm, Red Dot 荷重 0.74N)`** を配置します。
  * ヒンジ支点からのレバー比（$\frac{14.40}{7.00} = 2.06\times$）により、ホイール頂点での実効押下荷重は **約 $185\,\text{gf}$**、ストロークは **$0.14\,\text{mm}$** となります。
  * 「コトッ」と静かで上品な押し心地でありながら、**高速スピン中のホイールを指の腹でサッと触れて止めるとき（接触荷重 $30 \sim 60\,\text{gf}$）には絶対にミドルクリックが暴発しない** 絶妙な重さに設定しています。

## 3. 電気回路・ファームウェアインターフェース仕様

### 3.1 モジュール側回路（IC 1個 ＋ コンデンサ 1個 ＋ スイッチ 1個のみ）
* **非接触磁気角度センサー**: ams OSRAM **`AS5600-ASOT`**（`SOIC-8`、12-bit = **1周 4,096 分割**、`I2C` 通信、3.3V動作、消費電流わずか $1.5 \sim 6.5\,\text{mA}$）。
* **軸端磁石**: シャフト西端に $\varnothing 3.0 \times 1.5\,\text{mm}$ **径方向2極着磁（Diametric）ネオジム磁石** を接着し、`AS5600` とギャップ $0.55\,\text{mm}$ で対向させます。
* **共通 6ピンコネクタ（`JST SH 1.0mm`：`SM06B-SRSS-TB`, LCSC `C160405`）**:
  * 現行 `curcur40` のトラックボールセンサー基板（`rJ3` / `J1`）と **完全に同じコネクタ型番** を採用し、部品表（BOM）の品種増加を防ぎます。
  * ピン配列：`1: +3V3` / `2: GND` / `3: SDA` / `4: SCL` / `5: SW_MID` / `6: NC (予備)`。

### 3.2 Stage 1（単体試作キャリア基板）と Stage 2（`curcur40-right` Rev2）の接続対応
1. **Stage 1：単体デスクトップ評価ポッド（`InertiaWheel-Eval-Pod`）**
   * `Waveshare RP2040-Zero`（USB-C 搭載）＋ JST SH 6ピンコネクタ ＋ M2固定穴を備えた約 $40 \times 30\,\text{mm}$ の小基板（ゴム足付き）を作成し、PCにUSB接続して単体スクロールデバイスとしてテストします。
   * 1周 4,096 分割の絶対角を `1 kHz` でポーリングするため、毎秒20回転の超高速フリックでも取りこぼしゼロで滑らかに追従します。
2. **Stage 2：`curcur40-right` Rev2 への統合（外形・ケース変更ゼロ）**
   * 現行 `curcur40-right` で `CKW12` が使用している3本のマイコンピン（`GP24`, `GP7`, `GP25`）をそのまま `SDA`, `SCL`（PIO I2C またはソフトウェア I2C）, `KEYEX1（ミドルクリック）` に割り当て、裏面に JST SH 6ピンコネクタを1個置くだけで、**メイン基板の外形・ネジ穴・トッププレート・3Dプリントケースを1ミリも変えずに統合完了**します。

## 5. Phase 2（試作データ作成フェーズ）の実装ステップ

本仕様に基づき、次フェーズ（Phase 2）では以下の3つを作成します：

1. **3D CAD モデリング（`build123d` STEP / STL 生成 ＆ 干渉検証）**:
   * JLCCNC 発注用 `SUS304` ホイール単体 STEP（横溝フルート＋中央 2way Oリング溝付き）
   * JLC3DP SLA 発注用 3パーツ（`17.8 × 17.8 mm` ベースフレーム、一体揺動キャリッジ、$\varnothing 1.0\,\text{mm}$ 鋼球×18個スナップイン保持ハブ）および単体評価ポッド台座
   * `curcur40-right` フルアセンブリに仮配置した状態でのプレート・隣接キーキャップとの3D干渉ゼロ検証
2. **KiCad 基板設計（センサー小基板 ＆ 単体 USB-C 評価キャリア基板）**:
   * キャリッジ西側面に取り付ける極小 `AS5600` センサー基板 ＋ 静音スイッチ配線基板
   * `RP2040-Zero` を載せて机上で単体スクロールデバイスとしてすぐ試せる評価キャリア基板（DRC / ERC / JLCPCB 発注データ対応）
3. **単体試作用ファームウェア（QMK / Pico SDK）**:
   * `AS5600` の 12-bit 角度を高速読み取りし、1ノッチ（$20^\circ$ = 18ノッチ/周、またはソフト設定で 24/36 分割）ごとの正確なスクロール出力と静音ミドルクリックを処理するファームウェア
