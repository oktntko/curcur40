# パッシブ磁気慣性ホイール 単体評価ポッド（`curcur40-wheel-eval`）ビルドガイド

本ガイドは、電磁クラッチや巻線コイルを使わずに **「高比重ステンレス削り出しホイール（`SUS304` 7.96g）× 脱脂ミニチュアベアリング × 渦電流ゼロの絶縁11球・非接触磁気ラチェット × `AS5600` 12-bit 磁気角度センサー」** で高速慣性スクロールと静音ミドルクリックを実現する **単体デスクトップ評価ポッド（`curcur40-wheel-eval`）** の資材調達・組み立て・ファームウェア書き込み・磁力チューニング手順書です。

> [!TIP]
> **単体評価ポッドから始めるメリット**
> 本ガイドで製作する **ホイールローター・一体揺動キャリッジ・11球ハブ・`AS5600` センサー小基板** は、そのまま将来の **`curcur40-right` Rev2（標準ポン付け版 ／ マウスホイール同等のロープロファイル沈み込み版の両対応）** に無改造で移植・流用できる共通コアユニットです。まずは机上の単体 USB-C デバイスとしてベアリング脱脂や磁石ギャップの感触をじっくり追い込むことができます。

# Step 1: 資材一覧と入手経路・発注ガイド

## 1-1. 全体構成の概要（4つの調達ルート）

単体評価ポッドを1台製作するための資材は、以下の **4ルート** で揃います（特殊な手巻きコイルや専用カスタムICは一切不要です）。

1. **JLCPCB（基板製造・PCBA）**: 評価キャリア基板 `curcur40-wheel-eval`（$48.0 \times 32.0\,\text{mm}$）＋ 角度センサー小基板 `curcur40-wheel-sensor`（$8.8 \times 8.8\,\text{mm}$）
2. **JLCCNC（金属CNC切削）**: `SUS304` ステンレス削り出しホイール `sus304-flywheel.step`（$\varnothing 16.80 \times 5.60\,\text{mm}$）
3. **JLC3DP（SLA 3Dプリント）**: 絶縁11球ハブ・一体揺動キャリッジ・モジュールベース枠・評価ポッド台座の4点
4. **国内通販（Amazon / 秋月電子 / 遊舎工房 / モノタロウ等）**: `Waveshare RP2040-Zero`、`DDL-520 (MR52)` ベアリング×2、$\varnothing 2.0\,\text{mm}$ 鋼球、$\varnothing 2.0\,\text{mm}$ 平行ピン、磁石2種、`Kailh Square Silent` 静音スイッチ、M2ネジ類

### JLCPCB 発注時の注意点
* **① 評価キャリア基板 (`curcur40-wheel-eval`)**:
  * **PCB Thickness**: `1.6 mm`、**PCBA Assembly Side**: **`Top Side`**（`J1` JST SH 6ピンコネクタ `C160405`、I2C プルアップ抵抗 `R1/R2 4.7kΩ` `C25900`、パスコン `C1 100nF` `C1525` の計4点が自動実装されます）。

## 2-2. Phase 1: RP2040-Zero 単体への QMK ファームウェア書き込み

基板へハンダ付けする前に、`Waveshare RP2040-Zero` 単体を USB-C ケーブルで PC に接続し、評価用 QMK ファームウェア（`curcur40_wheel_eval`）を書き込んで正常起動を確認します。

### ① ファームウェア（`.uf2`）のビルド
[`kbd_firmware/`](../kbd_firmware/) ディレクトリにて以下のコマンドを実行します：
```sh
cd kbd_firmware
kb=curcur40_wheel_eval make qmk-init
kb=curcur40_wheel_eval kr=rev1 km=default make qmk-compile
```
ビルドが完了すると `keyboards/curcur40_wheel_eval/qmk/qmk_firmware/.build/curcur40_wheel_eval_rev1_default.uf2` が生成されます。

### ② `RP2040-Zero` への書き込み
1. `RP2040-Zero` 上の小さな **`BOOT` ボタンを押したまま** PC に USB-C ケーブルを挿します（すでに接続中の場合は `BOOT` を押しながら `RESET` を1回押します）。
2. PC に **`RPI-RP2`** ドライブが表示されたら、生成された `.uf2` ファイルをドラッグ＆ドロップします。
3. 自動的に再起動し、HID マウス／キーボード複合デバイス **`curcur40 Inertia Wheel Eval Pod`** として認識されれば準備完了です（※本ファームウェアはセンサー未接続状態でもフリーズせず起動するよう設計されています）。

## 2-3. Phase 2: ミニチュアベアリングの脱脂洗浄（★最重要ステップ）

> [!IMPORTANT]
> **新品のミニチュアベアリングをそのまま組まないでください！**
> 新品の `DDL-520ZZ` / `MR52` には防錆・高負荷用の粘度の高いグリスが封入されており、**未脱脂のままだと粘性抵抗で弾いても1秒未満で止まってしまいます**。以下の脱脂を行うことで、空転持続時間が一気に **3〜7秒以上** へ劇的に伸びます。

1. **シールド板の取り外し（両面オープン化）**
   - オープン形（シールドなし `DDL-520`）を購入した場合はそのまま手順2へ進みます。
   - 両面金属シールド形（`DDL-520ZZ`）の場合は、ルーペで見ながら外輪溝に嵌まっている極細のC字止め輪の切れ目にデザインナイフの刃先をそっと引っ掛けて外し、金属シールド板を外して内部のボールが見える状態にします（片面だけ外しても洗浄可能ですが、両面外すと最も洗浄効率が高くなります）。
2. **パーツクリーナー浸漬・回転洗浄**
   - ガラス小瓶や金属トレイにベアリング2個を入れ、**速乾性ブレーキ＆パーツクリーナー** をベアリングが浸かるまで吹き付けます。
   - 液の中でピンセットや爪楊枝の先にベアリング内輪を通し、シャカシャカと軽く回して内部のグリスを完全に溶かし出します。
   - 一度液を捨て、もう一度新しいパーツクリーナーを吹き付けて仕上げ洗いし、キッチンペーパーの上で **3〜5分間完全に乾燥** させます。
3. **空転チェック**
   - $\varnothing 2.0\,\text{mm}$ シャフトにベアリングを通し、指で軽く弾いて「シャーッ」と抵抗なく軽やかに回り続ければ脱脂成功です（※オイルは差さないドライ状態、または極低粘度のドライ被膜剤ごく微量のみが最も長く回ります）。

## 2-4. Phase 3: 基板のハンダ付け（センサー小基板 ＆ 評価キャリア基板）

### ① センサー小基板（`curcur40-wheel-sensor`：$8.8 \times 8.8 \times 0.8\,\text{mm}$）
1. **表面（`F.Cu`）**: `U1`（`AS5600-ASOT`、`SOIC-8`）の **1番ピン丸印／面取り側** を基板シルクの1番マークに合わせ、8ピンをハンダ付けします。
2. **裏面（`B.Cu`）**: パスコン `C1`（`100nF`）と `C2`（`1μF`）をハンダ付けします。
3. **4極配線パッド（`J1`）への細線ハンダ付け**:
   - 裏面下端の4つのSMDパッド（シルク表記順に **`3V3` / `GND` / `SDA` / `SCL`**）に、長さ約 `55〜65mm` の柔らかい極細配線（`AWG30〜34`）を4本ハンダ付けします（または片側コネクタ付きの JST SH 6ピンケーブルの `Pin 1..4` 線材を直接ハンダ付けします）。

### ② 単体評価キャリア基板（`curcur40-wheel-eval`：$48.0 \times 32.0 \times 1.6\,\text{mm}$）
1. **`U1`: `Waveshare RP2040-Zero` の実装（基板西側）**:
   - USB-C コネクタが **西側外周（`-X` 側）** を向くように `RP2040-Zero` を基板表面のフットプリント上に載せ、端面のキャスタレーション（半月状の端面スルーホール）を外側からハンダ付けして固定します。
2. **`SW1`: `Kailh Square Silent` 静音スイッチの実装（基板東側・南東コーナー）**:
   - 基板東側のモジュール枠内・南東位置にある `SW1` スルーホール2穴に、表面側から `Kailh Square Silent`（$6.2 \times 6.2 \times 4.3\,\text{mm}$）を底面が基板に密着するまで差し込み、裏面で2ピンをハンダ付けします。
   - **足切り**: 裏面に飛び出したスイッチの足が評価台座に当たらないよう、ハンダ山の上でニッパーで短くカットします。
3. **センサー配線の接続（JST SH コネクタ `J1` または 直結パッド `J2`）**:
   - **方法A（着脱式：推奨）**: センサー小基板からの4本線を片側 JST SH 6ピンプラグ（`Pin 1: +3V3`, `Pin 2: GND`, `Pin 3: SDA`, `Pin 4: SCL`）に繋ぎ、基板北側の `J1` コネクタへ挿します。
   - **方法B（直結式）**: 基板中央にある4連直結パッド **`J2`（`1: +3V3` / `2: GND` / `3: SDA` / `4: SCL`）** へセンサー小基板からの4本線をそのままハンダ付けします（コネクタケーブル無しでもすぐ動かせます！）。

## 2-5. Phase 4: ローター（ホイール＋11球ハブ）とキャリッジの組み立て

1. **絶縁11球ラチェットハブへの鋼球スナップイン圧入**
   - SLA 造形した `ratchet-hub-11ball` の外周11箇所のポケット入口（$\varnothing 1.94\,\text{mm}$）に、**$\varnothing 2.00\,\text{mm}$ `SUJ2` 鋼球を11個** 順番に押し込みます。
   - 平らな机の上に鋼球を1粒置き、上からハブの穴を押し当てると「パチン」と気持ちよくスナップイン保持されます。11個すべてが奥まで均等に収まっていることを確認します。
2. **キャリッジへの脱脂ベアリング装着**
   - `wheel-carriage` の左右の軸受支柱にある $\varnothing 5.04\,\text{mm}$ 穴に、Phase 2 で脱脂した **`DDL-520 / MR52` ベアリングを左右1個ずつ** まっすぐ押し込みます。
3. **シャフト・ホイール・11球ハブの同軸組み付け**
   - キャリッジの中央空間に **西側：`SUS304` ホイール**、**東側：11球ラチェットハブ** を並べて保持し、横から $\varnothing 2.0 \times 14\text{〜}15\,\text{mm}$ ステンレス平行ピン（回転シャフト）を **`[西ベアリング] → [SUS304ホイール] → [11球ハブ] → [東ベアリング]`** の順に通します。
   - ホイールと11球ハブが左右のベアリング内輪ボスに軽く当たりつつ、キャリッジ内壁と一切擦れずに軽く空転する位置に合わせます（軸が緩い場合のみ、ホイール・ハブの軸穴内側に極少量の瞬間接着剤またはロックタイトを付けて固定します ※ベアリング内部には絶対に接着剤を入れないこと！）。
4. **西側シャフト端への径方向磁石接着 ＆ `AS5600` 基板装着**
   - 西ベアリングから外（西側）へ約 $1.0\,\text{mm}$ 出たシャフト端面に、**径方向2極着磁ネオジム磁石（$\varnothing 3.0 \times 1.0\,\text{mm}$）** を同軸に接着します。
   - キャリッジ西端の基板クレードル溝に **`curcur40-wheel-sensor` 小基板** を、`AS5600` IC パッケージ表面が磁石と約 $0.5 \sim 0.8\,\text{mm}$ の非接触ギャップで正対する向き（IC面が内側＝東向き）で差し込み固定します。

## 2-6. Phase 5: ベース枠・評価台座への組み付けと M2 ネジ磁力調整

1. **評価キャリア基板へのベース枠固定**
   - `curcur40-wheel-eval` キャリア基板の東側（`SW1` 静音スイッチが立っている側）に `wheel-base-frame` を載せ、裏面または表面から `M2 × 4.0mm` ネジ2本（`H5`, `H6`）で固定します。
2. **ヒンジピン連結（一体揺動キャリッジの組み付け）**
   - ベース枠の上に Phase 4 で組んだキャリッジを載せ、北端のヒンジ穴に $\varnothing 2.0 \times 16\text{〜}17\,\text{mm}$ ステンレス平行ピンを通して連結します。
   - ホイール頂点を上から軽く押したとき、南東のストライカーが `SW1`（`Kailh Square Silent`）を「コトッ」と静かにクリックし、指を離すとスイッチの復帰力で元の水平位置へ戻ることを確認します。
3. **評価ポッド台座（`eval-pod-stand`）への収納**
   - 台座裏面の四隅にゴム足を貼り、上から評価キャリア基板を納めて四隅（`H1`〜`H4`）を `M2 × 4.0mm` ネジ4本で固定します（西側の切り欠きに `RP2040-Zero` の USB-C ポートが揃います）。
4. **北東 M2 調整ネジによる「ノッチ感 ⇔ 慣性スピン持続時間」の無段階チューニング**
   - 先端にラチェット用ネオジム磁石（$\varnothing 1.5 \sim 2.0 \times 1.5\,\text{mm}$）を吸着・接着した `M2` ステンレスネジを、キャリッジ北東ボスのネジ穴へ北側からねじ込みます。
   - ホイールを指で弾きながらネジを少しずつ回してスイートスポットを探します：
     - **時計回りに締める（磁石を11球ハブへ近づける）**: 1ノッチごとの「コツ、コツ」という磁気ラチェット感が強くなります（近づけすぎると11球に接触するため、必ず非接触ギャップ $\ge 0.2\,\text{mm}$ を保ちます）。
     - **反時計回りに緩める（磁石を離す）**: 弾いたときに「トトトトト…」という微振動を伴いながら **3〜7秒間スーーッと回り続け、指で触れればピタッと止まる** 理想のバランス点が見つかります！

## 2-7. Phase 6: PC 動作確認・分解能カスタマイズ・トラブルシューティング

### ① PC での動作確認
1. USB-C ケーブルを `RP2040-Zero` に挿し、ブラウザや長いコードエディタ画面を開いてテストします：
   - **1ノッチ送り**: ゆっくり回したとき、磁気ノッチに合わせて正確に上下スクロールすること。
   - **高速フリック慣性スクロール**: 指で弾いて離したあと、ホイールが物理的に回り続けている間ずっと高速スクロールし続け、指の腹でホイールに触れて止めた瞬間にスクロールもピタッと止まること。
   - **静音ミドルクリック**: ホイールを押し込んだときに中クリック（`MS_BTN3`：オートスクロールや新しいタブで開く動作）が反応し、かつ高速回転を指で軽く止めたときには誤クリックしないこと。
   - **水平スクロール**: キーボードの `Shift` キーを押しながらホイールを回すと水平スクロールに切り替わること。

### ② スクロール分解能・回転方向のカスタマイズ（[`config.h`](../kbd_firmware/keyboards/curcur40_wheel_eval/qmk/qmk_firmware/rev1/config.h)）
好みに応じて [`rev1/config.h`](../kbd_firmware/keyboards/curcur40_wheel_eval/qmk/qmk_firmware/rev1/config.h) の定数を変更して再ビルドできます：
* **`#define WHEEL_NOTCHES_PER_REV 22`**（既定値 `22`）：
  * `11` に設定：物理11球の磁気デテント1山につき厳密に `1` スクロールステップを出力
  * `22` に設定（推奨）：一般的なマウスホイールに近い約 $16.4^\circ$ 刻み（物理1山あたり `2` ステップ）
  * `36` に設定：外周36フルートに一致する高密度ハイスピード出力（$10.0^\circ$ 刻み）
* **`#define WHEEL_INVERT_DIR 0`**：スクロール上下方向を逆にしたい場合は `1` に変更します。

### ③ トラブルシューティング
| 症状 | 主な原因と対処法 |
| :--- | :--- |
| **ミドルクリックは効くが、ホイールを回してもスクロールしない** | 1. センサー小基板とキャリア基板間の4本線（`3V3, GND, SDA, SCL`）の並び順またはハンダ不良を確認。<br>2. 軸端の磁石が **径方向着磁（Diametric）** になっているか、および `AS5600` との距離が離れすぎていないか（推奨ギャップ $0.4 \sim 1.2\,\text{mm}$）確認（ファームウェアは `AS5600` の磁石検出 `MD` ビットが立つと自動でロック解除します）。 |
| **弾いても1秒以内にすぐ止まってしまう** | 1. ベアリング（`MR52`）のグリス脱脂が不十分な可能性大 → パーツクリーナーで再洗浄して完全乾燥させる。<br>2. 北東の M2 磁力調整ネジを締めすぎて磁石が11球に近すぎる／擦れている → 反時計回りに半回転〜1回転緩める。 |
| **手を離して静止しているのに 1ステップ勝手に動くことがある** | 磁気デテントの山の頂点付近に止まった際の微小揺れの場合、[`config.h`](../kbd_firmware/keyboards/curcur40_wheel_eval/qmk/qmk_firmware/rev1/config.h) の `WHEEL_DEADBAND_LSB` を `6` から `10`〜`12` に増やすと完全にピタッと静止します。 |
